# 🏧 Cajero Automático

Proyecto de práctica desarrollado en **Python**, utilizando **Programación Orientada a Objetos (POO)**.

El objetivo es simular el funcionamiento básico de un cajero automático y, progresivamente, incorporar nuevas funcionalidades.

## 📌 Estado actual

El proyecto se encuentra **en desarrollo**.

Actualmente cuenta con:

* 🔐 Verificación de PIN *(en desarrollo)*
* 💰 Extracción de dinero
* 💵 Consulta de saldo
* 📋 Menú interactivo por consola

Se continuará ampliando el proyecto con nuevas funciones a medida que avance su desarrollo.

## 🛠️ Tecnologías utilizadas

* Python
* Programación Orientada a Objetos (POO)
* Git
* GitHub

## 📂 Estructura del proyecto

```text
cajero-automatico/
│
├── cajero.py
├── main.py
└── README.md
```

### `cajero.py`

Contiene la clase `Cajero` y la lógica principal del sistema, como:

* Validación del PIN
* Consulta de saldo
* Extracción de dinero

### `main.py`

Contiene la interacción con el usuario y el menú principal del cajero.

## ▶️ Ejecución

Para ejecutar el programa:

```bash
python main.py
```

Luego se podrá interactuar con el cajero desde la consola.
